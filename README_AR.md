# أداة تحليل الكلمات

برنامج بسيط بلغة C++ بيحلل النص ويحسب عدد الحروف.  

## المميزات
- يحسب عدد الحروف بدون المسافات
- واجهة سطر أوامر بسيطة
- سريع حتى مع الملفات الكبيرة

## التقنيات المستخدمة
- **اللغة**: C++17
- **المفاهيم**: التعامل مع النصوص
- **البرنامج**: Visual Studio 2022
